# Mahidhar Reddy Patukuri

I build machine learning models that have to obey the equations of the system they describe, and I care about how far their answers can be trusted. I finish an M.S. in Data Science at Texas A&M University-Corpus Christi in December 2026.

## Research interests

Physics-informed machine learning for differential equation models in biology and medicine, Kolmogorov-Arnold networks (KANs), parameter estimation and identifiability from sparse, censored data, and uncertainty quantification.

## Selected work

**Neural network solvers for nonlinear ODEs.** A benchmark of MLPs against B-spline and Chebyshev KANs as physics-informed solvers on five ODEs, under one training budget. Submitted to *Machine Learning: Engineering* (IOP Publishing). Code available on request.

**M.S. thesis, 2026.** Physics-informed KANs for the de Pillis tumor-immune model under chemo-immunotherapy, solving it forward and estimating its parameters from sparse, noisy data. Code available on request.

## Skills and tools

Python (PyTorch, NumPy, SciPy), R, SQL, LaTeX, Git, Linux, SLURM on an HPC cluster. Profile likelihood, censored-data likelihood, Monte Carlo dropout, stiff ODE solvers.
